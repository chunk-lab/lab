# 差し替え用画像素材一覧

盤面の絵は現在仮の図形です。各ファイルは透明背景の WebP または PNG、正方形の 512×512 px を推奨します。主役の形は中央の 80% 以内に置き、上下左右に余白を残してください。画面上では約 45〜70 px で表示されるため、輪郭と色で一目で区別できる構図が適します。画像内に名前・レベル・個数・ロック・光・効果音を描き込む必要はありません。アプリ側が重ねます。

## 背景・画面装飾　2枚以上

- 港の朝市の横長背景 `background/harbor.webp`。推奨 1536×512 px。住人カードの後ろに敷きます。
- 作業台のタイル `background/board-tile.webp`。推奨 256×256 px。通常・暗いロック状態の2種類があれば使い分けられます。
- 生成・合体の光、きらめき、飛び出す粒は CSS で制御しているため、画像の追加は必須ではありません。演出用の粒画像を作る場合は透明な 128×128 px を推奨します。

必要な最小枚数は **町人14 + 品物96 + 生成機6 + 部品12 + 背景2 = 130枚** です。生成機を6段階すべて別絵にすると、さらに30枚増えます。

## 受け渡しと組み込み

画像は上記のファイル名でフォルダーごとまとめていただければ、IDから引くように `merge/` 内の表示を差し替えられます。町人の名前はゲーム内のデータに合わせています。潮見さんは旧名「砂吹さん」に相当します。現在の `residents/suna.webp` は既存 ID の維持用です。音は現時点で Web Audio から生成しているので音声ファイルの用意は必須ではありません。専用音を作るなら、生成、合体、ロック解放、お届けの4種類を短い OGG または MP3 でご用意ください。
