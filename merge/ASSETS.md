# 差し替え用画像素材一覧

盤面の絵は現在仮の図形です。各ファイルは透明背景の WebP または PNG、正方形の 512×512 px を推奨します。主役の形は中央の 80% 以内に置き、上下左右に余白を残してください。画面上では約 45〜70 px で表示されるため、輪郭と色で一目で区別できる構図が適します。画像内に名前・レベル・個数・ロック・光・効果音を描き込む必要はありません。アプリ側が重ねます。

## 背景・画面装飾

- 港の朝市の横長背景 `background/harbor.webp`。推奨 1536×512 px。
- 作業台のタイル `background/board-tile.webp`。推奨 256×256 px。通常とロック状態の2種類があると使い分けられます。
- 飛び出す粒やきらめきは CSS で描画します。

推奨素材の合計は **町人14 + 品物66 + 生成機4 + 部品8 + 背景2 = 94枚**。Lv.9の2品は特別合成確定後に描いても構いません。

## 受け渡しと組み込み

画像は上記ファイル名でフォルダーごとまとめれば、`merge/` 内で表示を差し替えられます。潮見さんの画像IDは旧名から引き継いだ `suna` です。チャンク君の登場・配布・退場には提供済み立ち絵を使います。
