# 第1話「ちょっと、外に出たい」

勉強部屋に追加した「第1話」から任意に開始する。既存のメニューは残し、自動再生や既存の解放条件の変更は行わない。

## 内容

はな → ストリーム初級単語セット1 → 疲れた、という会話 → 既存の読む・聞く第1章 → want to の表現 → 英語脳アプリで I / want to / rest / play → 町へ出る。

- `first.js`: 台本とゲームへの起動オプション、完了条件。
- `progress.js`: 進行の保存と判定。保存キーは `cs:town-episodes:first` のみ。
- `view.js` / `view.css`: 会話・開始・中断・再開・2D/3D切り替え。
- `town3d/src/episode-room.js`: 既存キャラ・家具モデルを使用した、物語専用の部屋。プレイヤーの姿や自宅配置を変更しない。

3Dは物語用の部屋のカットシーン。第1話中の操作は会話・ゲーム選択で、最後に通常の3Dの町へ移る。2DはSVGの部屋の絵と既存レッスンのキャラ画像を使用し、3D用スクリプトを読み込まない。最後は既存の2D地図へ移る。

## 既存アプリとの接続

- ストリームは既存の `wordset: {lv:1,k:0}` を使用。`stream / done / stream.word / w1-1 / finished:true` を受けて続ける。
- 読む・聞くは任意の追加オプション `storyChapter:1` で第1章を直接開く。台本・問題・採点・保存先は既存のもの。`story_clear` の章番号1で続ける。
- 英語脳アプリは任意の追加オプション `episodePractice:'want-to'` で、同じアプリを `sandbox="allow-scripts"` のフレーム内で実行。永続ストレージと親画面のDOMへのアクセスは許可しない。保存はメモリ内のみで、通常アプリの文・登録語・受け渡し箱に触れない。選択と表示は実際の英語脳アプリの `pick` / `render` を使用する。
- `core.host.onClose` は追加の通知。従来の `core.onClose` を置き換えない。通常の開閉・ゲームごとのセーブ名前空間は維持。
- 読む・聞くの非同期会話には、中断した会話が後から再開した画面を変更しないためのガードを追加。

イベントを途中で閉じても未クリアをクリアにしない。完了通知を受けた直後に終了・再読み込みしても、次回はその先へ進める。再読はイベントの進行だけを戻す。

単語練習とレッスンの実際の学習結果は従来どおり本来のセーブに記録する。既存の記録・コイン・ミッション処理も維持する。物語中の別のミッション案内はCSSで隠し、中断・終了後に表示できる状態を保つ。

## 検証

`series` で次を実行する。

```sh
npm install
npm test
node build.mjs town
npm run test:episode-dom
```

DOM結合テストは、実際のストリーム起動、途中終了・再開、既存レッスン第1章の3問、英語脳アプリの体験、町への切り替えを確認する。英語脳アプリの既存dbの完全一致・通常画面の作りかけ入力の維持・クリア済み第7章の維持も確認する。ストリームの完了は通知を注入して接続を検証し、プレイ全体の実行は対象外。

ブラウザの確認用ビルドでも、単語20問の実プレイ、第1章の3問、実際のsandbox内の英語脳アプリでの組み立て、物語への復帰、2Dの町への移動まで確認済み。3Dの初期化に失敗した場合の2Dへの切り替えも確認済み。切り替えの案内が次の場面に残る問題を修正した。

ブラウザ用のローカルプレビュー基盤は利用できないため、公開済みのGitHub確認用ビルドを使用。確認に使用したクラウドブラウザはWebGLのコンテキストを作成できず、3D描画そのもの・実際の音声出力・スマホ実機は未確認。本番の `polish` には未反映。

操作の調整：中断は上部の「物語メニュー」を開いた中に配置し、練習中の画面下には重ねない。英語脳アプリは I want to play. を用意してから通常の画面を直接操作できる。案内用の単語ボタンと操作ロックは廃止し、文中の I や play から主役・動きを変更する。通常アプリの操作・保存処理は変更しない。

現行の第1話：会話は2D固定。そらの一枚絵は左右反転し、退出時に初めて3Dの町を開く（2Dの町への入口も併設）。単語体験は既存設定 fs=1.4（大）で開始。want to / wants to は英語脳アプリの --aux と同じ #7a4ad9。英語脳体験は通常の主役タブ→sheの実選択→完成画面で称賛→次へ、の一方向。練習中の共通「街へ」は非表示、中断は物語メニューから。変更箇所の検証は node tests/episode-controls.cjs で直接対象場面を起動する。
