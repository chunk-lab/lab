# チャンクシリーズ

共通部品＋各ゲームを1つの置き場で管理し、ここから「街アプリ（全部入り・サブスク）」と「単体アプリ（別売り）」を組み立てる。
2人で作るときの手順・ルールは `CONTRIBUTING.md`。
設計の考え方は「チャンクシリーズ 統合の土台 設計書」を参照。

## 組み立て方
```
node build.mjs            # 全部のアプリ
node build.mjs town       # 街アプリだけ
```
→ `dist/<アプリ>/index.html`（Web版・スマホ版の元）、`dist/<アプリ>/artifact.html`（Claudeの公開ページ用）

## フォルダ
| フォルダ | 中身 | 直すのはどんなとき |
|---|---|---|
| `core/` | 共通部品：セーブ（store）・設定（settings）・音（sound）・読み上げ（speech）・権利（rights）・できごとの記録（events）・プロフィール（profile）・共通の画面（ui）・ゲームの開け閉め（host）・**辞書（dict）**・**読む画面（reader）**・チャンクの文の形（chunk） | 全アプリに関わること |
| `games/` | 各ゲーム。`game.js`（または game-*.js）が共通部品とのつなぎ口。`games/index.js` が一覧 | そのゲームの遊び方・画面 |
| `apps/town/` | 街アプリ（街の絵・建物の位置・施設の中身＝main.js の PLACES） | 街の見た目・施設に何を入れるか |
| `apps/solo/` | 単体アプリの土台（共通部品＋ゲーム1つ） | 単体アプリ共通のこと |
| `series.config.mjs` | 売るアプリの一覧（どのアプリにどのゲームを入れるか、最初から持っている権利）と、ゲームごとに公開するファイル | 新しく単体アプリを売る・中身を変える |
| `data/dict/` | 辞書の元データ（チャンクチャンクの2000語・約1万語、英語脳アプリの辞書） | 辞書の意味を直すとき |
| `tools/` | 組み立て用の道具（共通の辞書を作る build_dict.py など） | — |

## ゲームのつなぎ方
```js
export default {
  id: 'stream', name: 'チャンクストリーム', right: 'game:stream',   // right＝使うのに必要な権利
  async mount(el, ctx) { /* el の中に表示 */ return { unmount() { /* 片付け */ } }; }
};
```
`ctx` で使えるもの（`ctx.core.dict`・`ctx.core.reader` も）：`store`（そのゲーム専用のセーブ）・`settings`・`speech`・`sound`・`report(できごと, データ)`・`showBack(true/false)`・`exit()`・`opts`・`base`（そのゲームのファイルの場所）・`loadScript`・`core`

- ゲームはセーブ・音量・読み上げ・権利を自分で持たず、`ctx` を使う。
- コイン・課題・レベル・ステータスのために、ゲームは「何をしたか」を `ctx.report` で知らせるだけ（中身のルールは共通部品が決める。数字はこれから相談）。

## 共通の辞書と読む画面
- 辞書：`tools/build_dict.py` が `data/dict/` の チャンクチャンクの2000語（手直し済み・最優先）＋約1万語＋英語脳アプリの辞書（約2.9万語）＋熟語 を1つにまとめて `core/dict/data.js` を作る（組み立てのたびに自動）。意味を直すときは材料のほうを直す。
- 読む画面：`core.reader.open(story, opts)`。チャンクの色・単語/チャンクのタップ（発音＋品詞・意味）・訳・読み上げ・範囲の問題と選択肢の問題・答え合わせ・全文の読み上げ。中身は `core/reader.js`、見た目は `core/reader.css`、文の書き方と採点は `core/chunk.js`。
- 単語ドリルのカード（短い訳）は、同じ材料から `games/stream/tools/build_words2.py` が作る（長文で引く意味とドリルの訳は分けてある）。

## ぷにチャンク（games/punichunk）
| ファイル | 中身 |
|---|---|
| `game.js` | 街・単体アプリとのつなぎ（共通のセーブ・音・読み上げ・設定を渡す） |
| `src/app.js` | 全体のつなぎ（mount/unmount・画面の切りかえ・設定の保存） |
| `src/game.js` | 盤面の動き（バブル・連鎖・スロット・得点） |
| `src/grammar.js` | 文の判定（語順と役割の型）。チャンク・カードも使う |
| `src/dict.js` `dict_data.js` | ゲーム用の語の表（共通の辞書とは別。タグ・目的語の種類・難しさつき） |
| `src/seeds.js` `seed_data.js` `supply.js` | お題の文と、バブルの出し方 |
| `src/art.js` `audio.js` `ui.js` `tutorial.js` | 絵・効果音とBGM（音量は共通の設定）・画面・チュートリアル |
| `tools/` | 語の表・お題の文を作り直す道具（ふだんは使わない） |
設定の「音」は、共通の設定を開くボタンになっている。DESIGN.md / README.md はゲームのしくみの説明。

## チャンクチャンク（games/chunkchunk）
レッスン（文を作る・第1〜3章）は `src/make.js`（もとの make.js のまま、保存と効果音だけ共通部品に）。コインの入れ物は `src/wallet.js`（数字はまだ決めていない）。2人の絵は `assets/img/chara`。
入口は施設ごと（`apps/town/main.js` の PLACES で `opts.face` を指定）：学校＝`lesson`（レッスン＝文を作る・チャンク練習）、図書館＝`library`（リーディング・My Texts）、ゲームセンター＝`arcade`（さらさら・よーいどん・チャレンジ・ランキング）。
| 直したいもの | ファイル |
|---|---|
| 施設の入口（メニュー）の中身 | `src/view.html` の `#title`、つなぎは `src/title.js` |
| 流れる文を切るゲーム（判定・点数・絵・振り返り・設定） | `src/engine.js` |
| 文章を選ぶ画面（レベル・おすすめ） | `src/pick.js` |
| リーディング（共通の読む画面を開く） | `src/reading.js` |
| My Texts（長文の登録・問題・共有・AI用の指示文） | `src/texts.js` |
| 短文（登録・共有） | `src/shorts.js` |
| チャレンジ・ランキング | `src/rank.js` |
| 内蔵の文・お話・問題 | `src/data.js` |
| 見た目 | `src/cc.css`（`.ct-cc` の中だけに効く） |
