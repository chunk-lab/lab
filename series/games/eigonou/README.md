# 英語脳アプリ（games/eigonou）

絵を見ながら英文を組み立てる、辞書型のアプリ（もとは「英語脳ゲーム 試作7・スロット式」）。街では図書館から入る。

## 組み立て
- リポジトリ直下で `node build.mjs`。`src/main.js` を入口に、`g/eigonou/eigo.js`（と `eigo.css`）を別ファイルとして作る。
  とても大きい（約4.7MB）ので街の app.js には入れず、開いたときに読み込む（`game.js`）。
- 大きい辞書（BIGT）は全アプリ共通の `data/dict/big.js` をそのまま使う（共通の辞書の材料と同じもの）。

## しくみ（もとの1ページのアプリを、部品のファイルにしたときの約束）
- `src/` のファイルは、もとの試作7を作っていたファイルそのまま（中身は直していない）。並びは `src/main.js` の順番。
- どのファイルも、読み込んだときは宣言だけ。値を入れる・つなぐ処理は `init_<ファイル名>()` に入っていて、
  初めて開いたときに `main.js` がファイルの順番どおりに呼ぶ（もとの1つのスクリプトと同じ順番で動く）。
- ほかのファイルの関数を差しかえるところ（`render` に処理を足す など）は、`set_<名前>(…)` を呼ぶ形になっている。
  差しかえられる関数を持つファイルの最後に `set_◯◯` がある。
- 読み込み時に付けていた document / window の受け口とタイマーは `onDoc` / `onWin` / `onTick`（`src/env.js`）。開いている間だけ動く。
- 閉じるときは画面をそのまま取っておき、次に開いたときに戻す（作りかけの文もそのまま）。
- セーブは共通のセーブ（キー `db`）。前の保存（`eigonou_v1`）は初回に引っ越す。読み上げは共通の部品（声・速さ・音量は共通の設定）。
  アプリの設定の「音声」（選んだ部分／毎回文全体／なし）は、何を読むかだけを決める。
- 見た目は `src/eigo.css`（`.ct-eigo` の中だけに効く。アニメーション名は `eg-` つき）。画面のひな形は `src/view.html`。

|---|---|
| `i18n.js` | 画面の文字（多言語用の表） |
| `vocab.js` `vocab_a1.js` `vocab_a2.js` `cefr_map.js` | 基本の語彙・CEFR-J A1/A2 の追加・単語のレベル |
| `engine.js` | 文のしくみ（語彙・動詞の形・文→まとまり・日本語訳・文の完成チェック） |
| `pv_user.js` `idioms.js` `vcomp.js` `loc.js` `of.js` | 句動詞・熟語・to〜/〜ing・位置のまとまり・of のまとまり |
| `emoji_fix.js` `noto_map.js` | 絵文字の直し・絵文字の絵（約2MB） |
| `common.js` | アプリの状態・セーブ・読み上げ・設定・セット・ことば登録 |
| `pack.js` `addword.js` | ことばの共有形式・ことばを足す（AI判定つき） |
| `play.js` | 「つくる」画面の本体（流れ・絵・候補・時間の線・翻訳の共有 など） |

| `qbar.js` `qfw.js` `qsp.js` `qfr.js` `qfx.js` `coord.js` `geo.js` | 下の入力欄（打って進む）・機能語・続けて打つ・型・定型表現・名前と並列・地名 |
