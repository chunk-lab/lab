# 運営メモ(チャンクタウン)

運営がふだん触るのは、次の3つだけ。どれも直したら組み立て直す(`node build.mjs town`)と全アプリに効く。

| 変えたいこと | ファイル |
|---|---|
| 課題図書(週ごと)・話題の本・出さない本 | `data/library.js` |
| コイン・ダイヤ・枠・AIの回数・実力テストの回数などの数字 | `core/economy.js` |
| 遊びの並び(施設・「今日なにする?」・結果の帯のおすすめ) | `core/plays.js` |

家具の値段だけは 3Dの町の `town3d/src/game/furniture.js`。

## 運営画面

URL の最後に `?admin=1` を付けて開くと、設定(⚙)の下に「運営」ボタンが出る(`?admin=0` で消える)。

- 会員とお金を試す:有料/無料の切りかえ、ダイヤ・コインを足す、月替わりを試す
- 共有の教材:新着を棚へ・棚から外す・全員から消す(2回押し)、見直しの候補、通報
- 今週の課題図書と、数字の一覧の確認

いまは端末ごとの保存なので、運営画面で変えたことはその端末だけに効く。

## しくみの場所(作る人向け)

| しくみ | ファイル | 中身 |
|---|---|---|
| 記録 | `core/record.js` | 各アプリの報告(done・word・resume)を日ごとにまとめる |
| 勉強ノート | `core/notebook.js` `core/import.js` | 全アプリの言葉の置き場。前からあった言葉は1回だけ取り込む |
| 勉強部屋 | `core/study.js` | 今日・記録・勉強ノート・プロフィール(会員・お金) |
| 会員とお金 | `core/member.js` | 無料/有料、ダイヤ、1日の上限、月替わり、枠、AI・テストの回数 |
| 共有の教材 | `core/cloud.js` | 共有→新着(投票)→棚→見直し |
| 今日なにする? と結果の帯 | `core/today.js` | 属性表からおすすめ |
| この言葉を使ってみる | `core/useit.js` `core/ai.js` | 文をさがす・聞いてまねる・AIの判定と例文 |
| レベルと実力テスト | `core/level.js` | 最初のレベル判定、実力テスト、総合の点数 |
| 運営画面 | `core/admin.js` | 上の「運営画面」 |
| 図書館 | `games/library/` | 本の一覧(ストリームの長文・お話・共有の棚・自分の本) |
| ランダムチャンク | `games/listen/` | 声だけで聞いて意味を選び、まねして言う |

各アプリは「終わったら `ctx.report('done', {play, min, words, score, missed})`」「言葉を登録したら `ctx.report('word', {en, ja})`」を呼ぶだけ。新しい遊びは `core/plays.js` に1行足す。

## サーバー・課金につなぐとき

- アカウントと保存:`core/store.js`(セーブ)、`core/member.js`(会員・ダイヤ)、`core/cloud.js`(共有)の中だけを Supabase に置きかえる。画面側はそのまま。
- 課金(RevenueCat):`member.setPlan()` と `member.addGems()` を、ストアの購入結果から呼ぶ。
- CM:勉強部屋の「CMを見てコイン」は、いまは押すだけでもらえる仮のもの。広告を入れたら、見終わったときに `member.earn('cm')` を呼ぶ。
- 運営画面は、運営のアカウントだけに出す(`core/admin.js` の `on()`)。
