# ぷにチャンク 設計メモ

タイトル:**ぷにチャンク**(英語脳バブルパズル)/マスコット:チャンクくん

## 画面構成(縦画面)
```
┌ HUD:一時停止 / スコア / コンボ / 残り時間バー ┐
│ プレビュー帯:作っている連鎖・文をリアルタイム表示 │
│                                              │
│   フィールド:単語・チャンクのバブルが漂う      │
│                                              │
│ チャンクくんの道:コンボで体節が伸びる/アイテム │
└ スロット:前置 / 主語 / 動詞 / 目的語 / 後置 / 後置 ┘
```
フィールド・道・スロットは1枚のCanvas(入力も1系統)。HUD・プレビュー・各画面はDOM。

## モジュール構成(src/ → build.py で1つのIIFEに連結)
| ファイル | 役割 |
|---|---|
| util.js | 乱数(シード付き)、数学、イージング、DOMヘルパー |
| dict_data.js | 生成済み辞書(tools/mkdict.js が eigo_nou から生成) |
| dict.js | 既定の辞書アダプタ、語形変化(複数形・三単現・過去・ing・比較) |
| grammar.js | 純粋関数。連鎖→チャンク判定、差し込み、形の切替、文/節の解析と実現(活用・一致)、エラー文言 |
| supply.js | 供給(目標比率・不足優先・最低保証・詰み防止) |
| audio.js | Web Audio の効果音・BGM(手続き生成)、読み上げ |
| art.js | バブルのスプライト生成、チャンクくん、街並み背景、アイコン |
| game.js | 盤面状態、物理、入力、スロット、スコア/時間/コンボ、モード、ヒント、アイテム |
| tutorial.js | 体験型チュートリアル(台本+指アニメ) |
| ui.js | 全画面のDOMとCSS(接頭辞 pc-) |
| app.js | mount/unmount、アダプタ、画面遷移 |

## データの流れ
供給(supply) → 盤面アイテム(単語) → タップ連鎖(grammar.chainState) → チャンク
→ 一筆書き/スロット(grammar.parseSentence) → 成功:消去・得点・時間・読み上げ・補充 / 失敗:△×と理由、チャンクは盤面に残る

## 判定の型
- 名詞句 NP = (冠詞|数量詞|所有の顔)? (程度? 形容詞 -er/est?)* 名詞 | 顔 | 顔+顔(複数)
- 形容詞句 AP = 程度? 形容詞 -er/est?
- 前置詞句 PP = 前置詞 NP
- 動詞句 VP = 助動詞? not? be? 頻度? 動詞? 様態*(助動詞/be/動詞のどれか必須)
- 準動詞 NF = to/ing 動詞 様態* | 動詞 to/ing
- 副詞 ADV = 程度? 副詞
- 文 = 前置? 前修飾{0,2} 主語NP VP 補部 後置{0,3} (等位接続詞 節)?
  - 補部は動詞の型で決まる(他動=NP必須、自他=任意、自動=なし、二重目的語、連結動詞=AP、be=AP|NP|場所PP、to/ing をとる動詞=NF)
  - 前置 = 従属節(接続詞+節)|前置きの慣用句|文修飾の副詞
- 一致(常に自動):三単現、a/an、beの人称、代名詞の格、数詞・数量詞による複数形
- 手動のときだけ判定:冠詞、前置詞(時の名詞は厳密、場所はゆるく)、動詞の形、to/ing、-er/-est
- 時制:時の語(yesterday など)の許す時制と動詞句の時制を照合。時・場所の重複はバツ

## 判断の記録(仕様からの補正)
1. **チャンクの確定**:連鎖が成立している状態で0.9秒止まる、または連鎖に入らない語をタップすると確定。不成立のまま2秒止まると散る(2秒ルール)。毎回2秒待つとテンポが落ちるため。
2. **形の切替**:連鎖中の単語をもう一度タップすると形が変わる。完成後のチャンクは、タップで選択(全文表示・読み上げ・差し込み待ち)。
3. **一筆書き**:どのバブルからでも始められる。1語でチャンクになれる語(名詞・動詞・代名詞・副詞・慣用句など)はその場でチャンク扱い。1つだけ持ってスロットに離すとストック、それ以外の場所なら移動。
4. **be の been は省略**:完了形を扱わないため、be は「現在 ⇄ 過去」の2択。
5. **自動(動詞)**:文の完成時に、時の語から時制を決める。未来の語だけなら will を自動で補う。
6. **自動(冠詞)**:可算・単数で冠詞がなければ a/an を補い、不可算・複数に a が付いたら the に直す。
7. **名詞の単複**:連鎖中の名詞を再タップで切替。数詞・数量詞が付くと自動。
8. **難易度**:仕様のLv1〜3に、全部自動の「やさしい」を足した4段階。初めての人が30秒でルールを掴めるように。
9. **チャンクの形**:名詞句=まる、動詞句=たまご、修飾(PP/副詞/形容詞句/準動詞)=しずく、節・前置き=くも型。
10. **色**:品詞色は5色(名詞系=青、動詞系=赤、形容詞・副詞=緑、前置詞=黄、接続・前置き=紫)。色覚の違いは形とラベルで補う。
11. **-s の強調**:音声合成では一部だけ強調できないため、字幕で -s を強調表示。
12. **モード**:タイムアタック/あふれ/日替わり(プレミアム)に、時間制限なしの「フリー」を追加(練習用)。
13. **ペナルティは軽め**:×=-2秒、△=-1秒、連鎖が散る=時間減なし(コンボのみ切れる)。
14. **辞書**:eigo_nou の手作り辞書(約2,300語)から、判定に必要なタグが揃う語だけを変換。big.js(2.6万語)はタグが不足するため既定では使わない(辞書アダプタで差し替え可能)。
15. **日本語**:チャンク完成時だけ、意味を小さく表示(設定でオフ可)。
