# ぷにチャンク(PuniChunk)

英語を「チャンク(意味のかたまり)」でつかむ、スマホ向けのバブルパズル。漂う単語のバブルを英語の順にタップしてチャンクにし、チャンクを指でなぞってつなげると文が完成する。マスコットは「チャンクくん」。

- 外部ライブラリ・画像・音声ファイル・フォント・ネット上の素材は使っていない。絵(バブル・チャンクくん・街並み・アイコン)は Canvas と SVG、効果音とBGMは Web Audio、読み上げは端末の音声合成で作っている。
- 完全にオフラインで動く(外部への通信は0件)。

---

## 1. 遊び方

| 操作 | できること |
|---|---|
| 単語を英語の順にタップ | 連鎖がつながり、成立すると「チャンク」に合体する |
| 連鎖中の単語をもう一度タップ | 形が変わる(a⇄the、at→on→in、I→you→he→she→it、dog⇄dogs、to⇄-ing、-er⇄-est、時制など) |
| 連鎖中に冠詞・数量詞・所有の顔をタップ | 付け忘れを、連鎖の先頭へ差し込んで直せる |
| チャンクをタップ | 選択(全文と意味を表示・読み上げ)。続けて単語をタップすると、合う位置に差し込める |
| 選択中のチャンクをもう一度タップ | チャンク内の部品(to⇄-ing など)を切り替える |
| チャンクから指でなぞる | 一筆書きで文を作る。離すと判定 |
| バブルをスロットの帯までドラッグ | 下のスロット(前置き/だれが/する/なにを/どこ・いつ×2)に置く。主語と動詞がそろうと「わる!」ボタンが出る。押すか帯を上スワイプで割る。埋めた枠が多いほど倍率アップ(2枠×1.0・3枠×1.3・4枠×1.6・5枠×2.0・6枠×2.5) |
| バブルを下へはじく(フリック) | 合う空きスロットへ自動で入る。スロットのバブルを上へはじくと盤面に戻る |
| バブルをチャンクくんへドラッグ | 要らないバブルを食べてくれる。おなかは3つで、文を1つ作るごとに1つ回復 |
| 長押し | 全文と意味を表示。ヒント設定が「長押し」なら、つながる候補だけが濃く残る |

- **2秒ルール**:連鎖は、成立した状態で0.9秒止まると確定する。不成立のまま2秒止まると散る。
- **判定**:語順と役割の型だけを見る。意味がおかしい文も通る(読み上げると笑える)。
- **余波**:文がはじけると、近くに浮いている余り物の機能語(the・at・-er など)も一緒に割れる。長い文、スロットの大きな倍率ほど範囲が広い。
- **PERFECT!**:内部で想定している「タネ文」(下記)と同じ文を作ると、PERFECT! で得点が1.5倍+200。
- **△と×**:△は「惜しい」(主語・動詞・目的語のどれかが足りない)、×は型のくずれ。どちらも理由を短く表示する。

### 部品の種類(バブル)
| 部品 | 例 | はたらき |
|---|---|---|
| 助動詞 | can / will / must / should / may | 動詞の前。タップで can⇄could など |
| 助動詞の仲間 | want to / have to / need to / be going to / used to / would like to | 主語・時制で wants to・had to・is going to などに自動で変わる。be going to は未来、used to は過去だけ |
| 時制パーツ | 過去 / 未来 / 進行 | 動詞の直前か直後につなぐ。ran・will run・is running になる。タップで切替。時の言葉と矛盾すると× |
| not | not | 自動で don't / doesn't / didn't / can't / isn't などの短縮形になる |
| to / -ing | to/ing | 動詞の前で to+原形、後ろで -ing |
| -er / -est | -er | 形容詞を比較級・最上級にする |

### タネ文(盤面の作り方)
- 内部で、正しくて自然な文(タネ文)を2〜3本用意し、単語に分解して少しずつ流す。盤面の約65%がタネ文の部品で、残りはノイズ。どの語がどの文の部品かは見えない。
- 判定は型だけなので、タネ文どおりでなくても正しい文なら通る。タネ文どおりなら PERFECT!。
- タネ文は、辞書の「動詞がとる目的語の種類」(eat→食べ物、drink→飲み物など)と「時の言葉が許す時制」を使って自動生成する。2割ほどは chunk-chunk の例文(14文)から選ぶ。
- 慣用句は、タネ文の中で辻褄の合う形(`last night` は過去の動詞と、`a cup of` は数えない飲み物と)でしか出ない。ノイズから出る慣用句は、どの文にも付けられる前置きだけ。
- 難易度で型が変わる。やさしい=SV・SVO+場所、ふつう=助動詞・助動詞の仲間・時制パーツ・時、むずかしい以上=前置き・節・and/but/so。

### モード
| モード | 内容 |
|---|---|
| タイムアタック | 60秒から開始(上限90秒)。長い文ほど時間がのびる。ローカルランキングあり |
| あふれ注意 | バブルが一定間隔で増え、34個を超えたら終了。時間とともに間隔が縮む |
| フリー | 時間制限なし。一時停止メニューの「おわる」で結果へ |
| 日替わりお題(プレミアム) | 日付から決まる同じ盤面とお題で1日1回勝負。2回目以降は練習扱い |

### むずかしさ
| | 冠詞 | 前置詞 | 動詞の形 | to/-ing | -er/-est | 色 | 語彙 |
|---|---|---|---|---|---|---|---|
| やさしい | 自動 | 自動 | 自動 | 自動 | 自動 | 品詞 | CEFR 1 |
| ふつう | 手動 | 手動 | 自動 | 手動 | 手動 | 品詞 | 〜2 |
| むずかしい | 手動 | 手動 | 手動 | 手動 | 手動 | チャンクのみ | 〜3 |
| 鬼 | 手動 | 手動 | 手動 | 手動 | 手動 | なし | 〜4 |

設定の「自分で細かく決める」をオンにすると、項目ごとに自動・手動を選べる。三単現の -s、a/an、be の人称、代名詞の格、数詞による複数形は、どの難易度でも常に自動(文の完成時に -s を字幕で強調する)。

## 3. 別のアプリへの組み込み

`dist/punichunk.js` を読み込み、表示したい要素に `mount` するだけ。要素の大きさに合わせて描画し、横幅は最大520pxで中央寄せになる。

```html
<div id="puni" style="position:fixed;inset:0"></div>
<script src="punichunk.js"></script>
<script>
  const game = PuniChunk.mount(document.getElementById('puni'), {
    startScreen: 'title',            // 'splash' | 'title' | 'modes' | 'game'
    initialMode: 'ta',               // startScreen:'game' のときのモード
    dict: myDictAdapter,             // 省略時は内蔵辞書
    storage: myStorageAdapter,       // 省略時は localStorage(キーは 'punichunk:' 接頭辞)
    storagePrefix: 'punichunk:',     // 既定の保存アダプタの接頭辞
    audio: { bgm: .5, sfx: .8, voice: true, rate: 1 },
    onEvent: (name, data) => {},     // イベントの受け取り口
    services: { ranking: myRanking, store: myStore },
    insets: { top: 0, bottom: 0 },   // セーフエリアを外から渡す場合(省略時は env() から取得)
    pauseOnBlur: true,               // フォーカスが外れたら一時停止・消音(既定 true)
    dictCredit: 'クレジット画面に出す辞書の出典'
  });
  game.pause(); game.resume();
  game.setAudio({ bgm: 0, voice: false });
  game.show('modes');                // 'title' | 'modes' | 'game' | 'tutorial'
  game.getState();                   // { scene, mode, score, playing }
  game.unmount();                    // 後片付け(リスナー・音・DOM・スタイルをすべて外す)
</script>
```

- ES5相当の素のJSなので、eigo_nou のように `build.py` で連結する構成にも、そのままファイルとして足せる。
- CSSは `<style data-punichunk>` を1つだけ入れる。複数を同時に mount しても共有し、最後の unmount で消える。
- CommonJS の環境では `module.exports` からも取得できる。

### 4つのアダプタ

**1. 辞書アダプタ**(`options.dict`)
```js
{
  getWords({ pos, tag, maxLevel, minLevel, count, rnd, exclude }) → エントリの配列
  all(pos) → その品詞の全エントリ
}
// pos: 'noun' | 'verb' | 'adj' | 'adv' | 'idiom'
// tag: { cat, notCat:[...], k, c:[...], fr:[...], simple, cv, link }
// exclude: Set<string>(盤面にすでにある語)
```
既定の実装は `PuniChunk.adapters.dict(data)` で作れる。`data` を下のスキーマで用意すれば、2万語の辞書にも差し替えられる。

**2. 保存アダプタ**(`options.storage`)
```js
{ get(key) → 値 | null, set(key, 値), remove(key) }   // 値はJSONにできるもの
```
使うキー:`settings` `state` `best` `rank` `life` `daily` `store`

**3. 音**(`options.audio` と `setAudio()`)
`bgm`(0〜1)、`sfx`(0〜1)、`voice`(読み上げ on/off)、`rate`(読み上げ速度 0.8/1/1.15)。設定画面での変更も保存アダプタに残る。

**4. イベント**(`options.onEvent(name, data)`)
| name | data |
|---|---|
| ready | { version } |
| screen | { name, mode? } |
| start / end | { mode, score?, stats? } |
| chunk | { chunk, n } |
| sentence | { text, words, points, slot(倍率), info, perfect, shock(余波の数) } |
| eat | { item } |
| clause | { item } |
| fail | { kind:'chunk'|'sentence', code } |
| result | { mode, level, score, newBest, stats } |
| pause / resume / item / purchase | |

### サーバーが必要な機能(差し替え口)
**ランキング**(`services.ranking`)
```js
{ submit({ mode, level, score, sentences, longest, date }) → Promise, top(mode, level) → Promise<配列> }
```
**ストア・課金**(`services.store`)
```js
{ isPremium() → bool, inventory() → { hint, magic, auto }, consume(id) → bool,
  purchase(id) → Promise<bool>, price(id) → '¥120' 表記, isDummy?: bool }
// id: 'premium' | 'hint' | 'magic' | 'auto'
```
既定ではローカルのダミーが入る(購入は「テスト購入」で即成功し、初回は各アイテム3個)。

## 4. 辞書スキーマ

```js
noun:  { w, c, ad, cat, tg?, prep?, ts?, ind?, lv, ja }   // tg: 種類のタグ(ot と照合)
  c   'c' 可算 / 'u' 不可算 / 'p' 複数形のみ / 'n' 冠詞なし(固有名詞・曜日など) / 't' the が必要(morning など)
  ad  自動で付ける限定詞 'a' | 'the' | 'my' | ''
  cat 'person' | 'animal' | 'place' | 'time' | 'food' | 'thing' … (place と time は前置詞の判定に使う)
  prep 場所・時の名詞が使う前置詞(airport→'at'、Monday→'on'、morning→'in')
  ts  時の名詞が許す時制 ['pres','prog','past','fut']
verb:  { w, b, past, pp, s3, dbl, fr, tail?, dt?, cv?, link?, ot?, lv, ja }   // ot: とる目的語の種類 ['food','drink',…]
  w   表示(句動詞は 'pick up' のように tail 込み)  b 活用する語
  fr  'tr' 他動 / 'intr' 自動 / 'both'   dt 二重目的語   cv 'to'|'ing'|'both'(to/-ing をとる)   link 連結動詞(look happy)
adj:   { w, cmp?, sup?, more?, no?, jt, lv, ja }   // more:1 は more/most 型、no:1 は比較できない
adv:   { w, k, ts?, lv, ja }    // k: 'manner' | 'freq' | 'time' | 'place'
idiom: { w, k, ts?, q?, lv, ja } // k: 'front'(前置き) | 'time' | 'place' | 'other' | 'quant'(a lot of など)
lv: CEFR に合わせた 1〜4、ja: チャンク完成時に出す意味
```
冠詞・前置詞・助動詞・接続詞・程度の副詞・代名詞は、判定と切替に深く関わるので、辞書ではなく `grammar.js` の中に持たせている。

## 5. 判断の記録(仕様書からの補正)

1. **スロットは自動で決めない**:主語と動詞がそろっても勝手には割れず、「わる!」で自分のタイミングで割る。貯めて一気に割る楽しさを優先し、埋めた枠の数で倍率を上げた。
2. **チャンクの確定**:成立した状態で0.9秒(これ以上伸ばせないときは0.6秒)止まるか、連鎖に入らない語をタップすると確定する。不成立のまま2秒止まると散る。毎回2秒待つとテンポが落ちるため。
3. **形の切替は連鎖中**:連鎖中の単語を再タップすると形が変わる。完成したチャンクへのタップは「選択」にあて、2回目のタップで中の部品を切り替える。
4. **一筆書きはどのバブルからでも**:1語でチャンクになれる語(名詞・動詞・代名詞・副詞・慣用句など)は、その場でチャンクとして扱う。
5. **拾う判定は中心付近だけ**:一筆書きでは、バブルの中心から半径の約58%以内を通ったときだけ拾う。端をかすっただけで余計な語が入るのを防ぐため。
6. **なぞっている間は盤面が止まる**:漂い続けると、狙ったバブルが指から逃げるため。なぞりの取り消し(1つ前のバブルへ戻る)は、そこで0.3秒とどまったときだけ働く。ジグザグに通り過ぎただけで取り消されないように。
7. **スロットの帯の上では「運ぶ」**:スロットへ運ぶ途中で別のバブルを通っても、一筆書きにならない。
8. **冠詞の付け忘れを直せる**:手動モードで名詞を先にタップしても、連鎖中なら冠詞・数量詞・所有の顔を先頭に差し込める。
9. **be の been は省略**:完了形を扱わないため、be は「現在⇄過去」の2択。
10. **動詞が自動のとき**:文の完成時に時の語から時制を決める。未来の語だけなら will を補い、過去の語なら can→could にする。
11. **冠詞が自動のとき**:可算・単数で冠詞がなければ a/an(人の名詞は my、the の名詞は the)を補い、不可算・複数に付いた a は the に直す。
12. **名詞の単複**:連鎖中の名詞を再タップで切替。数詞・数量詞が付くと自動。
13. **難易度は4段階**:仕様書の Lv1〜3 に、全部自動の「やさしい」を足した。初めての人が30秒でルールをつかめるように。
14. **チャンクの形**:名詞句=まる、動詞句=たまご、修飾(前置詞句・副詞・形容詞句・to/-ing)=しずく、節と前置き=くも型。慣用句には星を付ける。
15. **色は5色**:名詞系=青、動詞系=赤、形容詞・副詞=緑、前置詞=黄、接続・前置き=紫。色覚の違いは形とラベルで補う。
16. **-s の強調は字幕で**:音声合成では一部だけを強調できないため、文完成のバナーで -s に下線を引く。
17. **フリーモードを追加**:時間制限なしで練習できる場がほしいため。
18. **ペナルティは軽め**:×は−2秒、△は−1秒、チャンクの誤りは−1秒。連鎖が散るだけなら時間は減らない(コンボは切れる)。
19. **時間延長は経過時間で弱める**:上級者だとタイムアタックが終わらなくなるため、50秒を過ぎると延長量を減らし、150秒で15%まで下げる。
20. **あふれの間隔は時間でも縮む**:文を作るほど、また時間がたつほど出現が速くなる(最短0.55秒)。上級者でも数分で決着がつく。
21. **ヒントのコスト**:「長押し」はコンボが3割減る。「いつも」はコスト代わりに倍率の上限を1.8倍に抑える。
22. **辞書**:eigo_nou の手作り辞書(約2,300語)から、判定に必要なタグがそろう語だけを使う。big.js(約2.6万語)はタグが足りないので既定では使わない(辞書アダプタで差し替え可能)。不適切語は変換時に除外している。
23. **日本語**:チャンクの完成時と長押し時だけ、意味を小さく出す(設定でオフにできる)。
24. **前置きの時との重複**:When 節などの時の表現と、主節の時の表現が重なったら×にする(仕様書の未決事項4)。
25. **詰み防止は2段構え**:供給の時点で「主語・目的語になれる数(手動の冠詞なら冠詞の数も)」と動詞を数えて補い、さらにプレイ中は2秒ごとに盤面を探索する。文が1つも作れなければ、古い機能語を救済の1語(冠詞・代名詞・自動詞のどれか)と入れ替える。
26. **フィールドの広さに合わせる**:画面が小さい端末では、バブルを最大2割小さくし、数も減らす(375×667 で約17個、430×932 で約22個)。

---
27. **チャンクくんが食べる**:要らないバブルは、チャンクくんへドラッグすると消せる。捨て放題にすると盤面を選ぶ緊張感がなくなるので、おなか3つ・文で1つ回復にした。
28. **余波は機能語だけ**:名詞や動詞まで割ると、使いたい語まで消えてしまうため。
29. **タネ文方式**:ランダムに単語を撒くと、絶対につながらない慣用句や、噛み合わない名詞と動詞が出る。内部で理想の文を作ってから分解して流すことで、慣用句・時制・助動詞の辻褄が合うようにした。全部をタネ文にすると答え探しになるので、約35%はノイズにしている。
30. **手動モードのタネ文**:動詞・be・助動詞の仲間は原形で出し、形はプレイヤーが選ぶ(答えを見せないため)。
31. **否定は短縮形**:実際の会話に近い don't / doesn't / isn't などで表示・読み上げる。
32. **時制パーツは「ふつう」から**:「やさしい」では、時の言葉から時制を自動で決める。
33. **つなぐ順番はゆるく**:先に `the airport` を作ってしまっても、あとから `at` を足せる。選択したチャンクに `at` をタップする、`at` をタップしてからチャンクをタップする、一筆書きで `at` を通る、のどれでも `at the airport` になる。連鎖の途中で順番から外れた語(`the dog` の途中の `big`)も、入る位置があれば自動で差し込む。英語の順に並べる練習は、表示と読み上げで担う。
34. **画面から外れたら静かに**:タブの切替だけでなく、フォーカスが外れたとき・表示領域から消えたとき・大きさが0のときも、音を止めて一時停止する(埋め込み先の画面で閉じられても鳴り続けないように)。止めたくない場合は `mount` に `pauseOnBlur: false` を渡す。
35. **品詞の最低数と上限**:タネ文と比率だけに任せると、助動詞・be・not がほぼ出なかった(22個中0.1〜0.8個)。盤面22個あたりの最低数(名詞4・動詞3・助動詞と助動詞の仲間2・be 1・冠詞2・前置詞2・形容詞2・副詞1・to/ing 1・部品1・代名詞1・接続詞1、ふつう以上は not 1)を満たすまで優先して出し、冠詞4・前置詞3・代名詞3・慣用句2などには上限を設けた。タネ文にも、全レベルで助動詞・want to・to/-ing を入れる。
36. **フリックでスロットへ**:バブルを下へ素早くはじくと、合う空きスロットへ自動で入る。スロットから上へはじくと盤面へ戻る。ゆっくり動かしたときや、チャンクくん・スロットの帯の上で離したときは、フリックとみなさない。
37. **一筆書きの誤反応を減らす**:(1)速く通り過ぎたバブルは拾わず、指が減速したか0.07秒とどまったバブルだけを拾う。(2)拾うと確実に×になる並び(自動詞のあとの目的語など)のバブルは、赤く揺れるだけで加えない。足りないだけの△(目的語がまだ無いなど)は、続きを作れるので拾う。
38. **正しい順番は○、違う順番は△**:タップ・なぞりのどちらでも、順番が違う語は正しい位置に並べ直してくっつけるが、「△ 正しい順番:〜」を出して得点は半分、コンボも伸ばさない。むずかしい・鬼で動詞の形を自動で合わせた場合(be + arrive → be arriving)も△。
39. **1語だけではチャンクにしない**:1語を押して余白をタップしても、選択が外れるだけ。1語のままでも、なぞれば文につながる。
40. **なぞりの誤爆対策(追加)**:途中で拾ったバブルのせいで次がつながらないときは、それを外して指の行き先を優先する。離したときも、始めと終わりを残して途中を外した並びを試す(並べ替えはしない)。なぞっている間は、つながる候補のバブルを常に光らせる。
41. **タネ文は1本ずつ丸ごと出す**:部品を複数の文に混ぜて少しずつ出すと、盤面に1文ぶんがそろわなかった。いまは1文の部品をまとめて出し、盤面に組める文が常に2本以上ある状態を保つ。古い語の入れ替えでも、タネ文の部品は消さない。
42. **直前のチャンクへの自動合体は副詞・-er/-est だけ**:次のチャンクの1語目が前のチャンクに吸い込まれる誤動作があったため。
43. **タネ文は英語脳の文生成エンジンで作る**:自作テンプレートとチャンクチャンクの例文をやめ、英語脳(eigo_nou)のエンジン(主語と動詞・動詞と目的語の相性チェック、目的語ランキング、時制に合う時の語)で作った自然な文2,000本を使う(`node tools/mkseeds_en.js <eigo_nou/src> 2000`)。96%に場所・時・様子の副詞句、39%に慣用句が入る。日本語訳も一緒に持つ。
44. **文のかけら**:なぞった並びがまだ文になっていないとき(she + buy など)は、消さずに「文のかけら」として残す。かけらは他のチャンクとなぞってつなげられ、下のバーへ運ぶと「だれが・する」などのスロットに分かれて入る。2つ以上つないでいる途中でバーに入っても運びモードにならず、スロットのチャンクもそのまま拾える。スロットは種類に合う順に選ぶ(前置詞句は「どこで」、名詞は「だれが→なにを」)。完成した文でも、下のバーで離せばすぐ割らずにスロットへ入る(貯めて「わる!」で倍率)。スロットから上へなぞって、また下のスロットへ戻る一筆書きもできる。
45. **なぞり中の候補**:1語ではチャンクにならない語(can / want to / the / at など)も、続ければつながるなら光らせる。主語のあとは助動詞・want to・動詞、副詞句のあとは主語や the(the のあとは名詞)。副詞句のあとに主語なしで動詞が来る並びは候補にしない。
46. **時の語は2つまでOK**:「日」+「時刻・時間帯」(yesterday + in the morning / at seven)で時制がかみ合えば通す。yesterday + tomorrow、yesterday + last week はダメ。
47. **タイトルから直接モードへ**:「むずかしさ」はモード選択画面から設定画面に移した。設定はタイトル左上の歯車から開く。
48. **読み上げの解錠**:iPhone は最初の読み上げをタップ中に呼ばないと、以後すべて無音になる。最初に指を離したときに無音の読み上げをして解錠する。Chrome の一時停止固まり対策に resume も入れた。

## 8. ストア公開に向けて

- `dist/index.html` を Capacitor などで包めば、iOS/Android アプリになる。縦固定・セーフエリア・バックグラウンドでの一時停止・ダブルタップ拡大の無効化は対応ずみ。
- 読み上げは端末の音声合成に頼るため、声は機種によって変わる。使えない端末では、設定画面にその旨を出し、字幕で代わりにする。
- アプリアイコンやスプラッシュ画像など、ストアの申請に必要な画像は含めていない。
- 課金とランキングは、`services.store` と `services.ranking` を本物につなぎ替える。

## 9. クレジット・ライセンス

- グラフィック・効果音・BGM・チャンクくん:すべて本プログラムで生成。
- 辞書:「英語脳ゲーム」(eigo_nou)の手作り辞書をもとに `tools/mkdict.js` で変換。辞書を差し替えるときは、出典を `options.dictCredit` に渡すと、クレジット画面に表示される。EJDict(CC0)や WordNet(Princeton WordNet License)を使った辞書に差し替える場合は、その表記をクレジットに加えること。
